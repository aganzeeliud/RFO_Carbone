Dataset Catalog

Primary data sources used for the Okapi Wildlife Reserve Carbon Sequestration and Storage (2018-2025).

Lidar

NASA GEDI L4B

Gridded Aboveground Biomass Density (1km resolution) derived from the Global Ecosystem Dynamics Investigation.

  • Years: 2019-2023
  • Format: GeoTIFF / Raster
Optical

Global Forest Watch

Hansen Global Forest Change dataset providing annual tree cover loss and gain at 30m resolution.

  • Years: 2000-2024
  • Format: Web / API / GEE
Radar

ESA Biomass CCI

European Space Agency Climate Change Initiative providing global maps of above-ground biomass.

  • Years: 2010, 2017-2022
  • Format: NetCDF / Raster
Vector

WDPA / Protected Planet

World Database on Protected Areas providing the official boundaries for the Okapi Wildlife Reserve.

  • ID: 124389
  • Format: Shapefile / GeoJSON
